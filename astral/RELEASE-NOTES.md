# Astral.AI 0.3.2

This release fixes shared form-control styles, settings spacing, switch sizing, hidden file inputs, and several layout problems in smaller windows. Navigation and help text use clearer labels. Existing characters, chats, profiles, memory, and appearance choices remain compatible.

The repository now belongs to ItsDTYT/Astral.AI. SillyTavern's license and attribution remain in place. AI tools helped with code, interface design, and documentation. Character portraits and backgrounds were generated with AI; some UI elements were created with AI assistance.

Choose the installer for a normal installation, or extract the portable ZIP and run Astral.AI.exe. Both builds are unsigned. Models are separate downloads. CPU support is included; GPU support is an optional in-app download.

See the repository README for setup and the validation record for test results and limitations.
